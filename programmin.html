String & Array

Program 1: Two Sum with Optimal One-Pass Hash Lookup

Finds two numbers in an array that add up to a target sum in $O(N)$ time.

import java.util.*;

public class TwoSumRunner {
    public static void main(String[] args) {
        int[] nums = {2, 7, 11, 15};
        int target = 9;
        Map map = new HashMap<>();
        
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                System.out.println("Found match: index " + map.get(complement) + " and " + i);
                return;
            }
            map.put(nums[i], i);
        }
    }
}
Java 8 Streams

Program 2: Grouping & Frequency Counting with Java 8 Streams

Counts occurrences of each element in a collection cleanly using streams.

import java.util.*;
import java.util.stream.Collectors;

public class StreamCounter {
    public static void main(String[] args) {
        List items = Arrays.asList("apple", "banana", "apple", "orange", "banana", "apple");
        Map countMap = items.stream()
            .collect(Collectors.groupingBy(item -> item, Collectors.counting()));
        System.out.println("Frequencies: " + countMap);
    }
}

Concurrency & Virtual Threads

Advance Q1 (2026): Java 21 High-Concurrency Virtual Thread Pool

Spawns millions of lightweight virtual threads for high-throughput microservices without carrier thread starvation.

import java.util.concurrent.*;

public class LoomSandbox {
    public static void main(String[] args) throws Exception {
        try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
            for (int i = 1; i <= 5; i++) {
                final int id = i;
                executor.submit(() -> {
                    System.out.println("Task #" + id + " executed on " + Thread.currentThread());
                    return id;
                });
            }
        }
    }
}
Data Structure Design

Advance Q2 (2026): Production-Ready LRU Cache Implementation

Doubly LinkedList + HashMap implementation providing strict $O(1)$ operations.

import java.util.*;

public class LRUSandbox {
    public static void main(String[] args) {
        LinkedHashMap cache = new LinkedHashMap<>(16, 0.75f, true) {
            @Override
            protected boolean removeEldestEntry(Map.Entry eldest) {
                return size() > 3; // Evict if size exceeds 3
            }
        };
        cache.put(1, "A"); cache.put(2, "B"); cache.put(3, "C");
        cache.get(1); // Access 1 to make it most recently used
        cache.put(4, "D"); // Evicts key 2
        System.out.println("Remaining in LRU cache: " + cache.keySet());
    }
}
